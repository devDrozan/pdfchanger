# PDF Changer

PDF Changer is a private, offline mobile app for photographing documents, making PDFs from images, and combining PDFs. It is being built for Android and iPhone.

The app and its setup instructions are in [mobile/README.md](mobile/README.md). Current user-facing behavior is described in [SPEC.md](SPEC.md).

The public [privacy policy](https://devdrozan.github.io/pdfchanger/) is hosted with GitHub Pages. Website source and update instructions are in [docs/README.md](docs/README.md).
