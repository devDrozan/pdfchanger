# PDF Changer privacy policy website

Public privacy policy for PDF Changer by Robindev, based on the user-facing section of `../Privacy_Policy_Draft.md`. The internal audit is not part of the website.

This is a static HTML page with inline CSS, no JavaScript, and no third-party fonts or analytics. Open `index.html` in a browser to preview it. GitHub Pages publishes this directory from the repository's `main` branch; keep `.nojekyll` so the files are served directly.

Public URL: https://devdrozan.github.io/pdfchanger/

To update the policy, edit `index.html`, update the effective date when data practices change, and commit the website files to `main`. The app's release SDK behavior, permissions, backup behavior, and Play Console Data safety declarations still need the verification recorded in `Privacy_Policy_Draft.md`. Publishing this page does not certify the app's compliance or add an in-app policy link.
